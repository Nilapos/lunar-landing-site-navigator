# Lunar Landing Site Navigator

Our project for the [NASA Space Apps Challenge 2026](https://www.spaceappschallenge.org/2026/challenges/lunar-landing-site-navigator/): an interactive tool to explore the Moon and compare candidate landing sites.

## Getting started

Requires [Node.js](https://nodejs.org) (LTS) and Git.

```bash
git clone https://github.com/Nilapos/lunar-landing-site-navigator.git
cd lunar-landing-site-navigator
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Project layout

| Folder | Content |
|---|---|
| `src/components/` | React components (UI) |
| `src/styles/` | Design tokens and CSS |
| `src/data/` | Landing site data |
| `src/lib/` | Scoring and other logic |
